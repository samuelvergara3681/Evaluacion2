# Evaluación 2 - Software de Geolocalización

Este repositorio contiene la versión optimizada del software de geolocalización desarrollado en Python utilizando la API de Graphhopper Directions.

## Descripción del Proyecto

El script permite calcular rutas entre dos ubicaciones geográficas, ofreciendo:
- Interacción y mensajes completamente en español.
- Formato numérico de salida (distancias y tiempos) a un máximo de dos decimales.
- Narrativa de viaje paso a paso en español.
- Opción para finalizar el programa ingresando "s" o "salir".

## Requisitos Previos

- Python 3.x
- Librería `requests` (`pip install requests`)
- API Key activa de Graphhopper Directions
